# 👦 Giziku Anak - Panduan Sehat Ayah Bunda

Dashboard interaktif ini dirancang untuk membantu orang tua dalam memantau, menghitung, dan menjaga keseimbangan gizi harian anak usia sekolah (6-12 tahun) berdasarkan Standar Angka Kecukupan Gizi (AKG) Kementerian Kesehatan RI.

## Setup Environment - Anaconda

```bash
conda create --name giziku-dashboard python=3.9
conda activate giziku-dashboard
pip install -r requirements.txt
```
## Setup Environment - Shell/Terminal

```
mkdir dashboard-giziku
cd dashboard-giziku
pipenv install
pipenv shell
pip install -r requirements.txt
```
## Run streamlit app

```
streamlit run app.py

```
